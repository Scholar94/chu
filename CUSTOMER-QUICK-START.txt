CHURCH MANAGER CUSTOMER QUICK START

1. Install Node.js LTS.
2. Extract this folder.
3. Run INSTALL-FIREWALL.bat as Administrator.
4. Double-click START-SILENT.vbs.
5. Open http://localhost:3000 if the browser does not open automatically.
6. Paste the activation key supplied by the vendor.
7. Create the Owner/Pastor account during first-run setup.
8. To add staff: Owner > Staff Accounts.
9. For LAN computers use http://HOST-LAN-IP:3000.
10. For remote phone/laptop use Tailscale and http://HOST-TAILSCALE-IP:3000.
11. Never port-forward TCP 3000.
